# 🗺️ 지도 연동 및 빵집 DB 구축 가이드 (Step 14) - Next.js

## 1. 개요
단순히 텍스트로 빵집 이름을 적는 것을 넘어, **카카오맵**을 통해 실제 위치를 검색하고 등록하는 기능을 구현하기 위한 기초 공사 단계입니다.
**빵집 정보(이름, 주소, 좌표)**를 저장할 별도의 테이블을 만들고, Next.js에 **카카오맵 SDK**를 연동합니다.

## 2. 사전 준비 (DB 설계)

### 2.1. Bakeries 테이블 생성
Supabase **SQL Editor**에서 아래 쿼리를 실행하여 빵집 정보를 저장할 테이블을 만듭니다.

```sql
-- 1. 빵집 정보 테이블
create table public.bakeries (
  id bigint generated by default as identity primary key,
  name text not null,           -- 빵집 이름
  address text,                 -- 주소 (지번/도로명)
  lat double precision,         -- 위도 (Latitude)
  lng double precision,         -- 경도 (Longitude)
  place_id text,                -- 카카오맵/네이버맵의 장소 ID (중복 등록 방지용)
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. RLS 설정 (누구나 조회 가능, 인증된 유저만 등록 가능)
alter table public.bakeries enable row level security;

create policy "Everyone can view bakeries" 
  on public.bakeries for select using (true);

create policy "Authenticated users can insert bakeries" 
  on public.bakeries for insert with check (auth.role() = 'authenticated');

-- 3. Notes 테이블 수정 (선택 사항: 나중에 마이그레이션 할 예정)
-- 지금 당장 notes 테이블을 수정하진 않고, 추후에 bakery_id를 연결할 것입니다.
```

### 2.2. 타입 업데이트 (필수)
테이블을 생성했으므로 타입을 갱신합니다.
```bash
npx supabase gen types typescript --project-id "wcyoeixzjcnwbeplndgu" > src/types/supabase.ts
```

## 3. 카카오맵 API 설정

### Step 1. 키 발급
1. [Kakao Developers](https://developers.kakao.com/) 접속 및 로그인.
2. **"내 애플리케이션"** -> **"애플리케이션 추가하기"**.
3. 생성된 앱 선택 -> **[앱 키]** 메뉴에서 **JavaScript 키** 복사.
4. 좌측 메뉴 **[플랫폼]** -> **Web 플랫폼 등록** 클릭.
5. 사이트 도메인 등록:
   - 로컬 개발용: `http://localhost:3000`
   - (나중에 배포 주소도 여기에 추가해야 합니다)

### Step 2. 환경 변수 설정
프로젝트 루트의 `.env.local` 파일에 키를 추가합니다.

```env
# ... 기존 Supabase 키들 ...
NEXT_PUBLIC_KAKAO_MAP_KEY=발급받은_JavaScript_키
```

### Step 3. 라이브러리 설치
카카오맵을 리액트 컴포넌트로 쉽게 쓰기 위해 라이브러리를 사용합니다.

```bash
npm install react-kakao-maps-sdk
```

## 4. 구현 단계 (Step-by-Step)

### Step 1. 카카오맵 스크립트 로더 생성
**파일 경로:** `src/components/common/KakaoMapScript.tsx`

`layout.tsx`에서 스크립트를 미리 로드해두는 컴포넌트입니다.
`react-kakao-maps-sdk`를 쓰더라도 기본 SDK 로딩은 필요합니다.

```typescript
'use client'

import Script from 'next/script'

const KAKAO_SDK_URL = `//dapi.kakao.com/v2/maps/sdk.js?appkey=${process.env.NEXT_PUBLIC_KAKAO_MAP_KEY}&libraries=services,clusterer&autoload=false`

export default function KakaoMapScript() {
  return (
    <Script
      src={KAKAO_SDK_URL}
      strategy="beforeInteractive"
      onLoad={() => {
        console.log('Kakao Map Script Loaded')
      }}
    />
  )
}
```

### Step 3. 지도 테스트 페이지 생성 (임시)
**파일 경로:** `src/app/map-test/page.tsx`

지도가 잘 뜨는지 확인하기 위한 테스트 페이지입니다.

```typescript
'use client'

import { Map, MapMarker } from 'react-kakao-maps-sdk'
import { useState, useEffect } from 'react'

export default function MapTestPage() {
  // 로딩 상태 관리 (스크립트 로드 타이밍 이슈 방지)
  const [isLoaded, setIsLoaded] = useState(false)

  useEffect(() => {
    if (window.kakao && window.kakao.maps) {
      setIsLoaded(true)
    } else {
      // 스크립트가 아직 안 불려왔을 경우를 대비한 폴백
      const interval = setInterval(() => {
        if (window.kakao && window.kakao.maps) {
          setIsLoaded(true)
          clearInterval(interval)
        }
      }, 100)
      return () => clearInterval(interval)
    }
  }, [])

  if (!isLoaded) return <div className="p-10 text-center">지도 불러오는 중...</div>

  return (
    <div className="w-full h-screen p-4">
      <h1 className="text-2xl font-bold mb-4">🗺️ 카카오맵 연동 테스트</h1>
      <Map
        center={{ lat: 37.5665, lng: 126.9780 }} // 서울시청 좌표
        style={{ width: '100%', height: '400px', borderRadius: '12px' }}
        level={3}
      >
        <MapMarker position={{ lat: 37.5665, lng: 126.9780 }}>
          <div style={{ padding: '5px', color: '#000' }}>서울시청 빵집?</div>
        </MapMarker>
      </Map>
    </div>
  )
}
```
