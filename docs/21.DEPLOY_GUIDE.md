# 🚀 프로젝트 배포 가이드 (Step 21) - Vercel

## 1. 개요
완성된 빵지순례 앱을 **Vercel**에 배포하여 누구나 접속할 수 있는 **실제 웹 사이트**로 만듭니다.
배포 후에는 Supabase와 카카오 개발자 센터의 **도메인 설정**을 수정해야 로그인이 정상적으로 작동합니다.

## 2. 배포 절차 (Step-by-Step)

### Step 1. GitHub에 코드 푸시
현재 작업한 모든 코드가 GitHub 저장소에 올라가 있어야 합니다.

```bash
git push origin main
```

### Step 2. Vercel 프로젝트 생성
1. [Vercel 대시보드](https://vercel.com/dashboard)에 접속하여 로그인합니다.
2. **"Add New..."** -> **"Project"** 클릭.
3. GitHub 저장소 목록에서 빵지순례 프로젝트의 **"Import"** 버튼 클릭.

### Step 3. 환경 변수 설정 (중요!)
배포 설정 화면의 **Environment Variables** 섹션을 열어 `.env.local`에 있던 값들을 모두 입력합니다.

| Key | Value (내용은 .env.local 참고) |
| :--- | :--- |
| `NEXT_PUBLIC_SUPABASE_URL` | `your_supabase_project_url` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `your_supabase_anon_key` |
| `NEXT_PUBLIC_KAKAO_MAP_KEY` | `your_kakao_javascript_key` |

* 값을 복사해 넣고 **Add**를 누르세요.
* 설정이 끝나면 **"Deploy"** 버튼을 클릭합니다.

### Step 4. 도메인 설정 변경 (필수!)
배포가 완료되면 Vercel에서 `https://your-project.vercel.app` 형태의 도메인을 줍니다.
이 주소를 각 서비스(Supabase, Kakao)에 등록해야 기능이 작동합니다.

#### 4-1. Supabase 인증 설정
1. **Supabase** 대시보드 -> **Authentication** -> **URL Configuration**.
2. **Site URL** 칸에 배포된 Vercel 도메인 입력. (예: `https://my-bakery.vercel.app`)
3. **Redirect URLs**에도 동일한 도메인 추가 (`https://my-bakery.vercel.app/**` 권장).
4. **Save** 클릭.

#### 4-2. 카카오맵 플랫폼 설정 (최신 경로)
지도가 정상적으로 뜨려면 도메인 등록이 필수입니다. 등록되지 않은 도메인에서는 지도가 하얗게 나오거나 에러가 발생합니다.

1. **[Kakao Developers](https://developers.kakao.com/)** 로그인 -> **[내 애플리케이션]** 클릭.
2. 작업 중인 앱을 선택하여 들어갑니다.
3. **왼쪽 사이드바 메뉴**에서 **[플랫폼]**을 클릭합니다.
4. **Web** 항목을 찾습니다.
   - **처음 등록 시:** **[Web 플랫폼 등록]** 버튼 클릭.
   - **이미 등록된 경우:** 우측의 **[수정]** 버튼 클릭.
5. **사이트 도메인** 입력창에 배포된 Vercel 도메인을 추가합니다. (줄바꿈으로 구분)
   ```text
   http://localhost:3000
   [https://my-bakery.vercel.app](https://my-bakery.vercel.app)
   ```
   *(주의: `https://`를 포함해야 하며, 주소 뒤에 `/`는 빼고 입력하세요.)*
6. **저장** 클릭.

## 3. 배포 후 체크리스트
- [ ] 1. Vercel 배포 URL로 접속 확인
- [ ] 2. **지도 확인:** 카카오맵이 정상적으로 뜨는지 확인 (도메인 미등록 시 에러 발생)
- [ ] 3. **로그인 확인:** Supabase 인증 후 다시 앱으로 돌아오는지 확인
- [ ] 4. 빵집 검색, 등록, 후기 작성 등 핵심 기능 테스트
- [ ] 5. 모바일에서 접속하여 반응형 UI 확인
